# Media Downloader (GUI)

Программа на Python + tkinter для скачивания:

- **Видео/аудио с YouTube, TikTok, VK, Instagram, X (Twitter), Rutube, Vimeo и ещё 1000+ сайтов** (движок yt-dlp)
  - видео в MP4 с выбором качества: Лучшее / 2160p (4K) / 1440p / 1080p / 720p / 480p / 360p
  - аудио в выбранном формате: mp3 / m4a / opus / wav / flac
- **Торрентов** — magnet-ссылки и .torrent-файлы (движок libtorrent), с прогрессом, скоростью, числом пиров и кнопкой «Отмена»

Тёмная тема, крупные поля и кнопки; интерфейс — две вкладки: «Видео / Аудио» и «Торренты».

## Запуск

```
python yt_downloader.py
```

или двойной клик по **«Скачать (GUI).bat»** (откроется без консольного окна).

## Портативный EXE — без установки Python

Готовый файл: **`dist/MediaDownloader.exe`** (~110 МБ, см. [Releases](https://github.com/icrafti/media-downloader/releases)).
Внутри уже всё нужное: Python, yt-dlp, libtorrent и **ffmpeg с ffprobe** — скопируйте файл
на любой компьютер с Windows 10/11 и запускайте двойным кликом. Настройки (`settings.json`)
и журнал ошибок (`error.log`) создаются рядом с exe.

- Для YouTube при бот-проверке дополнительно рекомендуется **Node.js** в системе.
- Сборка доверенная — используйте exe из официальных Releases этого репозитория.

Пересобрать exe самостоятельно:

```
pip install pyinstaller
python -m PyInstaller --onefile --noconsole --name MediaDownloader ^
  --add-binary "bin/ffmpeg.exe;." --add-binary "bin/ffprobe.exe;." ^
  --collect-all yt_dlp --hidden-import libtorrent yt_downloader.py
```

`bin/` — положите туда `ffmpeg.exe` и `ffprobe.exe` (подойдёт essentials-сборка с gyan.dev).
Проверить, что попало в сборку: `python build_diag.py` — или тем же набором флагов соберите
его в exe и запустите.

## Зависимости

```
pip install yt-dlp libtorrent
```

- **ffmpeg** в PATH — нужен для конвертации аудио и склейки видео+звука
- **Node.js** (или Deno) в PATH — yt-dlp использует его как JS-рантайм для YouTube
- **libtorrent** — ставится через pip (для вкладки торрентов)

## Удобства

- **Enter** в поле ссылки начинает скачивание.
- Настройки (режим, качество, формат, папки, куки) **запоминаются** между запусками — `settings.json` рядом с программой.
- Кнопки **«Обзор…»** (выбрать папку) и **«Открыть»** (открыть папку с файлами) у каждой вкладки.
- Ссылка/папка не теряются: поля растянуты на всю ширину окна.

Папка сохранения по умолчанию — «Загрузки» пользователя; у каждой вкладки своя, меняется кнопкой «Обзор…».

## Вставка ссылки

- кнопка **«Вставить»** или **Ctrl+V** (работает при любой раскладке клавиатуры),
- **правый клик** по полю — контекстное меню (копировать / вставить / выделить всё),
- если при открытии или клике в окно поле пустое, а в буфере ссылка или magnet — подставится сам.

Ссылки с параметрами плейлиста (`…&list=…`) скачиваются как одно видео.

## Известные особенности

- YouTube периодически требует «подтвердить, что вы не бот» (чаще всего на Shorts):
  программа сама пробует обходной клиент; если не помогло — включите **«Куки браузера»**,
  выберите браузер, **закройте его** (иначе база кук заблокирована) и повторите.
- Для расшифровки ссылок yt-dlp сам скачивает официальные скрипты-решатели с GitHub
  (remote components) — интернет до github.com должен работать.
- Для magnet-ссылок скорость зависит от числа сидов; если пиров нет 4 минуты, загрузка
  завершится с ошибкой «Пиры не найдены».
- Instagram/TikTok иногда требуют вход — используйте «Куки браузера» тем же способом.
- Если программа не запустилась, причина будет записана в `error.log` рядом с ней.
